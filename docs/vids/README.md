# Video

| File | What it is |
|---|---|
| `EZCanvas-Explainer.mp4` | A four minute explainer, narrated. Linked from the main [README](../../README.md) |

## What it covers

Seventeen slides in six chapters, following the library from the outside in.

| Chapter | Slides |
|---|---|
| Opening and overview | Title, then the four pieces: canvas, toolbar, state, export |
| 1. The tools | The ten tools, and the fourteen controls alongside them |
| 2. Configuration | Passing a set of tools and a set of controls, shown as code |
| 3. The integration | Two composables sharing one state |
| 4. Output | PNG export, transparent backgrounds, surviving rotation |
| 5. Architecture | One element model, one shared state, layers that depend one way |
| 6. Getting started | The JitPack dependency |

## Rebuilding it

The source deck is deliberately untracked, because it carries the narration audio and runs to
several megabytes. The rendered video is the artifact worth keeping in the repository.
