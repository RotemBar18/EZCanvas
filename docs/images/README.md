# Screenshots

Drop the six images the main README links to in this folder, using these exact names.

| File | What to capture |
|---|---|
| `canvas.png` | The main Canvas screen with a drawing on it and the toolbar sheet pulled up |
| `configure.png` | The Configure tools sheet, with several chips switched off |
| `examples.png` | The Examples gallery, scrolled so three or four cards are visible |
| `signature.png` | Signature Pad, signed, showing the delivery form around it |
| `markup.png` | Photo Markup with a photo loaded and a circle plus a text label on it |
| `neon.png` | Neon Art, a few glowing strokes, showing the dark toolbar |

Capture on a phone or emulator in portrait. In Android Studio use Running Devices, or from a
terminal:

```bash
adb exec-out screencap -p > docs/images/canvas.png
```
